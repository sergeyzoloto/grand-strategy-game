The "meta-technology" of the machine age — machines whose entire purpose
is making other machines' components to a precision no hand tool can
reliably match, the direct precondition for the interchangeable-parts
standardization ENG-210 covers.

## Timing

Wilkinson's precision boring machine (1775, initially developed to bore
accurate cannon and cylinder bores for Watt's steam engines) is an early
foundational case; Maudslay's screw-cutting lathe (from around 1800) and
successive milling and planing machine developments mature the field
through the 1840s.

## Mechanism

A machine tool achieves a level of dimensional precision and repeatability
no skilled hand-worker can reliably match unassisted, because the tool
itself — rather than the human hand — controls the cutting or boring
motion's exact path; this precision compounds recursively, since a
sufficiently accurate machine tool can be used to manufacture the next,
even more precise generation of machine tools, a self-improving cycle craft
hand-tool production has no equivalent to.

## Social consequence

Machine-tool precision shifts the scarce, valuable skill from the
individual craftsman's hand-eye coordination toward the machinist's ability
to set up, operate, and maintain the tool itself — a genuinely different
skill set, still requiring real expertise, but one that scales and
transmits differently than the years of hand-craft apprenticeship it
substantially displaces.

## Regional specifics

Wilkinson's boring machine's original purpose — accurate cannon and steam-
engine cylinder bores — ties this entry directly to ENG-170's steam-engine
development, each technology's improvement compounding the other's
capability. East Asian precision machine-tool capability arriving only
through later direct technology transfer, with no preceding independent
tradition, is consistent with the broader pattern already noted for steam
power specifically — this is a technology cluster that really did originate
and initially concentrate in Europe and the Americas without a parallel
independent development elsewhere.

## Hook

Machine tools achieve a precision and repeatability no hand-tool craft
can match, in a self-improving cycle where accurate tools build even more
accurate successors — the direct precondition for the interchangeable-parts
standardization (ENG-210) that follows, and a technology cluster that, in
this era, genuinely did originate and stay concentrated in only two regions.
